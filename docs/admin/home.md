# Introducción al panel de administración de GwaIO

Desde esta interfaz se puede gestionar la configuración del estudio, proyectos y usuarios. A este apartado tendrán acceso únicamente los usuarios con rol `admin`.

## Qué puedes hacer desde el panel
- Consultar un **dashboard** con métricas de estudio (proyectos, usuarios activos/inactivos y builds disponibles).
- Administrar la ficha del **studio** (nombre, URLs de instaladores, rutas de trabajo y configuración global).
- Crear y editar **proyectos** para que el launcher cargue plugins y rutas correctas.
- Dar de alta/baja **usuarios** y resetear contraseñas sin tocar la base de datos a mano.

> Aviso: solo los roles `admin` o `local_admin` tienen acceso al panel de configuración del estudio, proyectos y usuarios.

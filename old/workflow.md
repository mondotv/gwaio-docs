### Artists on-boarding with GwaIO


## Objective
This document has been made for the meeting due on the 13th of September 2023, which has the objective of analyzing and improving que on-boarding method of GwaIO for new artists.

## Installation
The process of installing GwaIO is nowadays handled 100% by IT at Tomavision, it can be summarized into the following points:
1. Creating a Tomavision Server User
2. Giving the new artists credentials for accessing the server
3. If the artist is working from remote, giving them the credentials of the VPN
4. Creating a GwaIO account for the artist.
5. Installing GwaIO through the executable file.
6. Showing the introductory video.

## GwaIO Workflow
# Receiving a Task
The process of receiving a task requires two things:
1. Comunicating the artist which task she has to work on, which is generally done by assigning the task to the artist and changing the status of the task from waiting to start to something else.
2. Having the artist receiving this information, which generally means either having the artist refresh the default "My Tasks" button or if the artist switched to either "Assets" or "Shots" having the artist refreshing those buttons and making sure they know how to filter tasks by their names.
